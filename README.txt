Project overview:
Tripistry is a travel web appplication. 
It makes it possible for travellers to easily book travel packages, and it alows travel agencies to create and upload these packages.

Stacks:
PHP - used for the api endpoints.
HTML and css for UI 
Javascripts for frontend integration and validation.

To run you need to connect to the database using the config.php by adding your mysql password and database name.
Put the Tripsitry folder in the htdocs in xampp then start apache and mysql.
To access use your borwser and search for localhost/Tripsitry/client
